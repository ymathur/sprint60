# Sprint 60

Daily timed JEE Main practice exams for a 60-day plan: accounts, results synced across devices, review, retry, an error log and squad rankings.

A static site served by GitHub Pages from the root of `main`. Accounts and data use Firebase Authentication and Cloud Firestore (project `sprint60-1638b`); the rules in `firestore.rules` are pasted into the Firebase console.

`index.html` is generated. Do not edit it by hand.
